# Polestar 猎萨双人 · 上海加尔

《魔兽世界：无限》部落猎人与萨满的简体中文双人路线。包含九段可独立打开的指南，从 50 级职业任务、沉没的神庙一路到海加尔山的第一个 18 格邮政背包。需要 Polestar 0.4.1 或更新版本。

## 用 WowUp 安装

1. 在 WowUp 选择 **WoW Forever**。
2. 打开 **获取插件 → 从 URL 安装**，粘贴本仓库地址。
3. 进入游戏后在 Polestar 指南菜单搜索「猎萨双人」。

手动安装可以从 [Releases](https://github.com/ufolyx-niper/PolestarPack_HunterShaman/releases/latest) 下载以 **-forever.zip** 结尾的安装包，解压到 Forever 客户端的 **Interface/AddOns**。

[查看插件说明、分段命令和资料来源](PolestarPack_HunterShaman/README.txt)。

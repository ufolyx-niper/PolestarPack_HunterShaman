# Polestar 猎萨双人 · 上海加尔

《魔兽世界：无限》部落猎人与萨满的简体中文双人升级指南，适用于 Polestar 0.4.1。从 50 级职业任务和沉没的神庙开始，经安戈洛、费伍德和冬泉谷，到海加尔山完成三段邮差任务，领取 18 格海加尔邮政背包。

## 在 WowUp 安装

1. 选择 **WoW Forever → 获取插件 → 从 URL 安装**，粘贴仓库地址 https://github.com/ufolyx-niper/PolestarPack_HunterShaman 。
2. 进入游戏后输入 `/polestar guides`，搜索「猎萨双人」，打开连续主线。两位玩家分别用自己的任务日志推进。
3. 跟随当前目的地和目标。副本走法写在对应目标的提示里，职业接取、材料数量、声望和邮件进度由角色状态判断。

也可以在 [正式版本](https://github.com/ufolyx-niper/PolestarPack_HunterShaman/releases/latest) 下载以 **-forever.zip** 结尾的安装包，解压到 Forever 客户端的 **Interface/AddOns**。

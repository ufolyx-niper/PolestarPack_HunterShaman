# Polestar 猎萨双人 50–60

《魔兽世界：无限》部落猎人和萨满的简体中文升级路线，适配 Polestar 0.4.1。跟随一条主线完成职业任务、野外任务圈和四个升级副本。每个副本提前安排个人能接的任务，按首趟进本规划。

- 安戈洛和棘齿城提前准备神庙的燃料与石环。去莫高雷时可带上「不稳定的魔法」，打副本顺手收微粒。
- 费伍德准备木喉声望，冬泉谷上山拿邮政背包，之后继续黑喉要塞和黑石深渊的野外前置。
- 瘟疫之地、海加尔与希利苏斯提供后段任务，安戈洛高地的造物者平台是最后一个计划副本。

## 安装或更新

在 WowUp 选择 **WoW Forever → 获取插件 → 从 URL 安装**，输入本仓库地址。已有旧版可以在 **我的插件** 中检查更新。进入游戏后输入 `/polestar guides`，搜索「猎萨双人」。

也可以从 [正式版本](https://github.com/ufolyx-niper/PolestarPack_HunterShaman/releases/latest) 下载安装包并解压到 Forever 客户端的 Interface/AddOns。需要先安装并启用 Polestar。

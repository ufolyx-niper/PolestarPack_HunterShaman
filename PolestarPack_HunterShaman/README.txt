Polestar 猎萨双人 · 上海加尔
版本 0.1.0，适用 WoW Forever（16001）和 Polestar 0.4.1。

安装
解压后，将整个 PolestarPack_HunterShaman 文件夹放到 _forever_/Interface/AddOns，和 Polestar 并列。回到游戏后 /reload，或从角色选择界面启用插件。两台电脑都安装相同版本。

打开
输入 /polestar guides，搜索「猎萨双人」。九段都可以单独打开。也可输入对应命令：
/polestar guide hunter-shaman-hyjal/start
/polestar guide hunter-shaman-hyjal/hunter
/polestar guide hunter-shaman-hyjal/shaman
/polestar guide hunter-shaman-hyjal/temple-prep
/polestar guide hunter-shaman-hyjal/temple
/polestar guide hunter-shaman-hyjal/ungoro
/polestar guide hunter-shaman-hyjal/felwood
/polestar guide hunter-shaman-hyjal/winterspring
/polestar guide hunter-shaman-hyjal/hyjal

跟路线走
单击目标前的勾选框确认手动步骤。任务、拾取、航点等也会读取游戏状态。接任务步骤以游戏日志里实际接取为准。遇到不做的支线，在 Polestar 里右键跳过目标或整步，之后可以复原。已经做到后面的角色可以直接打开对应章节。

猎人和萨满看到各自的职业目标。两人要分别在自己的日志确认已接神庙任务，跨峡谷前各查药水，最后各交邮件并确认拿到背包。Polestar 的组队面板可协助查看共同任务。副本内首领走法会显示成勾选步骤，入口箭头导向悲伤沼泽。

中文和数据
步骤与说明为简体中文。任务、NPC、物品使用固定 ID 和 Polestar 的本地化能力。少数 Forever 新名字没有可靠简中数据时显示英文。进山和补给走法包含玩家记录点位，具体任务窗口与航线以游戏为准。
